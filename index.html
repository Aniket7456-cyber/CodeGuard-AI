Vulnerable Code main.py (Original) 
import sqlite3

username = input("Enter username: ")
connection = sqlite3.connect("users.db")
query = "SELECT * FROM users WHERE username='" + username + "'"
result = connection.execute(query)
print(result.fetchall())
Recommended Secure Code main.py (Patched) 
import sqlite3

username = input("Enter username: ")
connection = sqlite3.connect("users.db")
# Using parameterized queries to prevent SQL Injection
query = "SELECT * FROM users WHERE username = ?"
cursor = connection.cursor()
cursor.execute(query, (username,))
print(cursor.fetchall())

AI Remediation Explanation (IBM Granite / Watsonx Architecture)

The original code directly concatenates untrusted user input into an SQL statement string. Parameterized queries (prepared statements) separate data from SQL instruction syntax, ensuring user input is never interpreted as executable code, completely neutralizing SQL Injection attacks.
