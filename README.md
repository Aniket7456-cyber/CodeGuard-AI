> **"Find vulnerabilities. Understand the risk. Fix it before deployment."**

---

## Overview

CodeGuard AI is an advanced, developer-first code security platform that bridges the gap between complex static analysis and actionable remediation. Designed with a sophisticated cybersecurity SOC dashboard aesthetic, it allows developers and students to scan source code instantly, understand the root cause of vulnerabilities through AI-assisted explanations, and apply verified secure code fixes.

---

## Features

- **Interactive Code Editor:** Multi-language support (Python, JavaScript, Java, C, C++, PHP, SQL) with syntax highlighting, line numbers, and live editing.
- **Client-Side Pattern Detection Engine:** Rule-based security analysis capable of detecting SQL Injection, XSS, Hardcoded Secrets, Command Injection, Weak Cryptography, and more entirely in the browser (zero backend required).
- **Dynamic Risk Scoring:** Algorithmic security scoring (0–100) with animated before/after remediation comparisons.
- **Deep Vulnerability Insights:** Detailed breakdown cards featuring CWE identifiers, confidence scores, affected lines, and beginner-friendly risk explanations.
- **AI-Assisted Secure Fixes:** Side-by-side diff comparison between vulnerable and secure code with one-click copy functionality.
- **Professional Security Reports:** Generate printable/downloadable PDF-ready executive security summaries.
- **Hackathon Demo Ready:** Instant preloaded sample vulnerabilities for rapid live demonstration.

## Deployment (GitHub Pages)

This project is 100% static and requires no server-side compilation, databases, or environment variables.

1. Clone or download this repository.
2. Push all files to a GitHub repository (`/index.html` at the root).
3. In your GitHub repository settings, navigate to **Pages**.
4. Set the source branch to `main` (or `master`) and save.
5. Access your live deployment at `https://<your-username>.github.io/<repository-name>/`.
